## ثانيًا: ما بقي

1. **تثبيت 1.8 من TestFlight يفشل** برسالة «التطبيق المطلوب غير متوفر أو غير موجود».
   - **حالة Apple (من `asc-check`):** البناء 49 صالح (VALID)، داخلي IN_BETA_TESTING، minOS 14، غير منتهي. المشكلة ليست في الرفع.
   - **خطوات مقترحة على الجوال:** الانتظار 10–15 دقيقة، إغلاق TestFlight وفتحه، إعادة تشغيل الجوال، تسجيل الخروج والدخول في App Store.
   - **إذا استمرت:** إعادة الرفع برقم بناء جديد (50) بنفس الأمر في القسم الرابع.
2. **تجربة 1.8 على الجوال** (قائمة الفحص في القسم الخامس).
3. **نشر تعديلات الخادم** (`b8a1dce`، محفوظة في المستودع ولم تُنشر):
   - `dalil-alerts`: صوت `dalil-rain.caf` لتنبيهات المطر غير الصامتة
   - `dalil-fayd`: صوت `dalil-rain.caf`
   - `dalil-admin`: صوت `dalil-event.caf` إذا كان الوسم يبدأ بـ `event-`، وإلا الافتراضي
   - `dalil-rooms` (`bgpos`): تمرير `age` في رسالة الموقع
   - **آمن في أي وقت:** إذا لم يجد الآيفون ملف النغمة يشغّل الصوت الافتراضي، و`age` الغائب يُعامل كصفر.
   - **قبل النشر:** قارن النسخة المنشورة بنسخة المستودع (`get_edge_function`) حتى لا تُستبدل تعديلات أحدث. الدوال كبيرة (~150KB مجتمعة) مع `_shared/apns.ts` و`_shared/common.ts` و`dalil-alerts/region-grid.ts`.
4. **دمج `ios-1.8` في `main`** بعد نجاح التجربة.
5. **إرسال 1.8 للمراجعة** في App Store Connect.
6. **قرار معلّق — تنبيهات العواصف «حساسة للوقت»:** لم يُضف. يحتاج أولًا أن يفعّل فهد خاصية Time Sensitive Notifications لمعرّف `com.alluhaybi.dalil` في developer.apple.com، ثم: إضافة الصلاحية `com.apple.developer.usernotifications.time-sensitive` في `ios.yml`، و`"interruption-level": "time-sensitive"` للعواصف الخطرة فقط (برد أو عاصفة رعدية فوقك أو قادمة) في `dalil-alerts`، ثم بناء جديد.
7. **مؤجل بقرار:** إخفاء شرح ألوان «متى المطر؟» خلف زر ⓘ.

## ثالثًا: تفاصيل تحديث الآيفون 1.8

كل الكود الأصلي داخل `.github/workflows/ios.yml` (سكربت Python في خطوة «Icon, splash and Info.plist» يضيف كلاسات Swift إلى `AppDelegate.swift` المولَّد من Capacitor).

| # | الميزة | التنفيذ |
|---|---|---|
| 1 | الموقع من الآيفون مباشرة (بدون رسالة github.io) | كلاس `DalilVC` (يرث `CAPBridgeViewController`) يضيف في `webViewConfiguration(for:)` سكربت عند بداية كل صفحة يستبدل `navigator.geolocation` و`permissions.query` بجسر للتطبيق (`dalilgeo`). الكلاس `DalilGeo` يقرأ الموقع بـ `CLLocationManager` ويرسله للصفحة. الإطار الداخلي للخريطة يستخدم جسر الصفحة الأم. الـ Storyboard يُعدَّل ليستخدم `DalilVC` (يفشل البناء إذا لم يُستبدل) |
| 2 | الكاميرا والمايكروفون بدون رسالة github.io | `DalilUIProxy` يغلّف `uiDelegate` حق Capacitor ويوافق على `requestMediaCapturePermission` لنطاق `f10f100a-debug.github.io` فقط. إذن النظام للتطبيق يبقى كما هو |
| 3 | نغمة المطر والحدث في الخلفية | خطوة «Notification sounds» تحوّل `assets/sounds/{rain,event}.m4a` إلى `www/sounds/dalil-{rain,event}.caf` بـ `afconvert` (أُضيف `assets/sounds` للـ sparse-checkout). عند التشغيل ينسخها `DalilSounds.install()` إلى `Library/Sounds` |
| 4 | الشاشة مضاءة أثناء التوجيه والتسجيل | أمر `awake` في `DalilBg` (مصدران: `main` و`map`) يضبط `isIdleTimerDisabled` |
| 5 | عمر موقع الخلفية | `DalilBg.send` يرسل `age` (عمر القراءة من GPS) |
| 6 | سبب فشل الصوت | `DalilPTT`: رقم خطأ Apple عند رفض بدء الإرسال، وسبب فشل التشغيل (`download`, `decode_N`, `play`, `play_nosession`, `finish`). تظهر في جدول `client_errors` (`ver='voice-diag'`) |

**ما تم التحقق منه:**

- البناء الموقّع رُفع: 1.8 (49)، تشغيل 41305672430، والصلاحيات موقّعة: aps production، push-to-talk، applinks.

## رابعًا: كيف تبنيه وترسله

```bash
# 1) بناء تجريبي بدون توقيع: يشتغل تلقائيًا مع أي push يغيّر native/ أو ios.yml (على أي فرع)
git push origin ios-1.8

# 2) بناء موقّع ورفعه إلى TestFlight (رقم البناء = رقم التشغيل تلقائيًا)
gh workflow run ios.yml --ref ios-1.8 -f upload=true -f version=1.8

# 3) فحص حالة النسخة في App Store Connect (قراءة فقط)
gh workflow run asc-check.yml --ref main
#    ولربط بناء بنسخة موجودة في App Store Connect:
gh workflow run asc-check.yml --ref main -f set_build=49
```

- **الأسرار المطلوبة** (موجودة): `APPLE_TEAM_ID`، `ASC_KEY_ID`، `ASC_ISSUER_ID`، `ASC_KEY_P8`.
- **الإرسال للمراجعة:** من App Store Connect: أنشئ نسخة 1.8 (المنشور حاليًا 1.6)، اختر البناء، ثم أرسل للمراجعة.

**الترتيب المقترح للإصدار:**
1. حل مشكلة التثبيت وتجربة TestFlight
2. دمج `ios-1.8` في `main`
3. نشر تعديلات الخادم
4. الإرسال للمراجعة

## خامسًا: قائمة فحص 1.8 على الجوال

1. **الأذونات:** احذف دليل وثبّت نسخة TestFlight. المتوقع رسالتان فقط: الموقع باسم «دليل»، ثم التنبيهات، **بدون** أي رسالة فيها github.io.
2. **الموقع:** النقطة تظهر وتتحرك في البوصلة والخريطة (المصغّرة والمكبّرة).
3. **الشاشة:** توجيه لنقطة أو تسجيل مسار لمدة دقيقتين، والشاشة لا تنطفئ.
4. **غرفة الرحلة:** رسالة صوتية تصل، والمواقع بلا قفزات (يلزم أن يحدّث كل الأعضاء).
5. **الكاميرا:** تصوير حدث بدون رسالة github.io.
6. **النغمات:** بعد نشر تعديلات الخادم، تنبيه مطر وتنبيه حدث والجوال مقفل.
